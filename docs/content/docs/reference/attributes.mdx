## `data-spotnote`

```html
<li data-spotnote="components/TodoList.jsx:18:8">
```

The element's source location, as `path:line:column`:

- `path` is relative to the Vite root, with `/` separators.
- `line` counts from 1, `column` from 0.
- The position is the start of the opening tag (`<`).

Added to every host element written in `.jsx`, `.tsx`, `.vue` and `.svelte` files outside `node_modules`. An element that already has a `data-spotnote` attribute is left as is.

## `data-spotnote-name`

```html
<li data-spotnote="components/TodoList.jsx:18:8" data-spotnote-name="TodoList">
```

The component that owns the element:

| File | Value |
| --- | --- |
| `.jsx` / `.tsx` | The nearest enclosing function whose name starts with a capital letter (`function TodoList`, `const TodoList = () =>`, also through `memo()` / `forwardRef()`). Omitted when there is none. |
| `.vue` / `.svelte` | The file name without its extension. |

## `<spotnote-root>`

A single element appended to `<html>` that holds all of Spotnote's UI in an open shadow root. It carries `data-spotnote-ui`, which Spotnote uses to ignore its own UI when it looks for elements under the cursor.

If your end-to-end tests run against the dev server, these attributes and this element are in the DOM there too.
