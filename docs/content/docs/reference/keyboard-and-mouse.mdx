---
title: Keyboard & Mouse
description: Every key and click Spotnote responds to.
---

## Selection mode

| Input | Action |
| --- | --- |
| Click the launcher | Open it and start selection mode, or close it and end selection mode. |
| Hold `Alt` (`⌥ Option`) | Selection mode while held. |
| Click an element | Open its note panel. |
| Click the Pause button | Pause or resume selection mode with the launcher open. |
| Drag the launcher | Move it; it snaps to the nearest corner. |

## Note panel

| Input | Action |
| --- | --- |
| `Enter` | Save the note and copy the prompt. |
| `Shift+Enter` | Line break. |
| `Esc` or **×** | Close. A new note is discarded; an edited note is saved. |
| Click another element | Move the panel to it. With unsent text, the panel shakes instead. |
| Click empty space | Close. With unsent text, the panel shakes instead. |
| Drag the panel | Move it (anywhere except the text field and buttons). |

## Pins and the notes list

| Input | Action |
| --- | --- |
| Click a pin | Open its note. |
| Click a note in the list | Scroll to its element and open it; switches page first if needed. |
| Copy / trash on a **Not found** note | Copy its saved prompt, or delete it. |
| Click the page while the notes list or Settings is open | Close it. That's all the click does: it doesn't pick an element or follow a link. Pins and the note panel work as usual and leave it open. |

## `Esc`

Closes one layer per press: the notes list, then the note panel, then selection mode (the launcher stays open, paused). When none of these is open, `Esc` reaches your app as usual.
