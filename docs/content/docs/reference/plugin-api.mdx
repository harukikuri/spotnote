## `spotnote()`

```ts
import type { Plugin } from 'vite';

export default function spotnote(): Plugin;
```

The package's only export. Call it with no arguments and add the result to `plugins`:

```ts title="vite.config.ts"
import spotnote from 'spotnote';

export default defineConfig({
  plugins: [react(), spotnote()],
});
```

It has **no options**.

## Plugin order

Order in `plugins` doesn't matter. The stamping `transform` hook is registered with `order: "pre"`, which runs before every hook without an order, including framework plugins that are themselves `enforce: "pre"` (Svelte, Solid).

```ts
plugins: [react(), spotnote()]
plugins: [spotnote(), svelte()] // same result
```

## Warnings

```
[spotnote] skipped pages/Editor.tsx — couldn't parse it, so its elements won't be pickable.
```

Printed once per file when the JSX pass can't parse a file. The file is passed on to your framework's compiler unchanged, so your app still works; only that file's elements can't be picked directly.
