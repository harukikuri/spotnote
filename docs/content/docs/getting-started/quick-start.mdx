## 1. Add the plugin to your Vite config

`spotnote()` is the whole setup — no options, no client import, no Babel wiring. It's `apply: "serve"`, so it activates in `vite dev` and is a no-op in production builds.

```ts tab="React" title="vite.config.ts"
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [react(), spotnote()], // [!code highlight]
});
```

```ts tab="Svelte" title="vite.config.ts"
import { defineConfig } from 'vite';
import { svelte } from '@sveltejs/vite-plugin-svelte';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  // spotnote() first — its enforce:"pre" stamp must run before Svelte's compiler
  plugins: [spotnote(), svelte()], // [!code highlight]
});
```

```ts tab="Vue" title="vite.config.ts"
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  // spotnote() first — it stamps the .vue template before Vue compiles it
  plugins: [spotnote(), vue()], // [!code highlight]
});
```

## 2. Start the dev server

```bash
pnpm dev
```

That's it. Spotnote stamps a `data-spotnote="file:line:column"` attribute on your host elements and auto-injects the picker into the page — no changes to your app code.

<Callout type="info" title="Production stays clean">
  Because the plugin is `apply: "serve"`, `vite build` never sees it — no
  `data-spotnote` attributes and no picker leak into your bundle.
</Callout>

## 3. Create a note

Open the printed `localhost` URL. Toggle **Inspect** in the launcher (bottom-left) or hold **`Alt`**, then hover and click an element to open the note panel.

<BrowserFrame url="localhost:5173">
  <SpotnoteDemo />
</BrowserFrame>

Type an instruction and hit **Add** (or `Enter`) — Spotnote copies an agent-ready prompt to your clipboard and drops a pin. Paste it into Claude Code / Cursor / Codex.
