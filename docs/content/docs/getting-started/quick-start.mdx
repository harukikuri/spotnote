This assumes Spotnote is [installed](/getting-started/installation).

## 1. Start the dev server

```bash
pnpm dev
```

Open the local URL Vite prints. A round `+` button sits in the bottom-left corner of the page: that's the **launcher**.

## 2. Pick an element

Click the launcher. It turns yellow and **selection mode** starts: as you move the cursor, an outline follows it with a label like `button .chip ProductCard.jsx:12`, with your framework's logo in front of the file name.

Click the element you want to change. The note panel opens next to it.

<BrowserFrame url="localhost:5173">
  <SpotnoteDemo />
</BrowserFrame>

## 3. Write the note

Type what should change, in plain words, and press `Enter`. Spotnote:

- copies the prompt to your clipboard (the launcher shows a ✓),
- leaves a numbered **pin** on the element, so you can reopen the note later.

You stay in selection mode, ready for the next element.

## 4. Paste it into your agent

Paste into Claude Code, Cursor, Codex or any chat. The prompt names the file, line and column of the element, so the agent edits the right place. When the change lands, Vite's hot reload shows it in the page.
