---
title: Quick Start
description: About 2 minutes. Click an element, write a note, paste it into your agent.
---

Spotnote needs to be [installed](/getting-started/installation) first.

<Steps>
<Step>

### Start the dev server

```bash
pnpm dev
```

Open the local URL Vite prints.

**You should see** <LauncherIcon /> in the bottom-left corner. That's the **launcher**.

</Step>
<Step>

### Click the launcher, then an element

Click <LauncherIcon />, then click the element you want to change.

**You should see** the launcher turn into <LauncherIcon state="open" />, an outline follow your cursor with a label like `button .chip ProductCard.jsx:12`, and, after your click, the note panel open next to the element.

<BrowserFrame url="localhost:5173">
  <SpotnoteDemo />
</BrowserFrame>

</Step>
<Step>

### Write what should change, press `Enter`

Plain words are enough: "make this pill-shaped".

**You should see** <LauncherIcon state="done" /> for a moment (the prompt is on your clipboard) and a numbered **pin** on the element. Click the pin later to reopen the note.

</Step>
<Step>

### Paste into your agent

Paste into Claude Code, Cursor, Codex or any chat.

**You should see** the agent edit the right file, and Vite's hot reload show the change in the page.

</Step>
</Steps>

You're still in selection mode, so you can click the next element right away. `Esc` pauses it.
