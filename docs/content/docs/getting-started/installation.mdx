## Install the package

```bash tab="npm"
npm install -D spotnote
```

```bash tab="pnpm"
pnpm add -D spotnote
```

```bash tab="yarn"
yarn add -D spotnote
```

## Requirements

- **Vite** 5.0 or later
- **Git** — required for commit tracking
- **Node.js** 22 or later
- One of: React, Vue, or Svelte
