---

## Requirements

- Vite 5 or later.

## 1. Install the package

Spotnote only runs in the dev server, so add it as a dev dependency.

```bash tab="npm"
npm install -D spotnote
```

```bash tab="pnpm"
pnpm add -D spotnote
```

```bash tab="yarn"
yarn add -D spotnote
```

## 2. Add the plugin

Add `spotnote()` to `plugins`. It takes no options, and where you put it in the array doesn't matter.

```ts tab="React" title="vite.config.ts"
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [react(), spotnote()], // [!code highlight]
});
```

```ts tab="Solid" title="vite.config.ts"
import { defineConfig } from 'vite';
import solid from 'vite-plugin-solid';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [solid(), spotnote()], // [!code highlight]
});
```

```ts tab="Vue" title="vite.config.ts"
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [vue(), spotnote()], // [!code highlight]
});
```

```ts tab="Svelte" title="vite.config.ts"
import { defineConfig } from 'vite';
import { svelte } from '@sveltejs/vite-plugin-svelte';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [svelte(), spotnote()], // [!code highlight]
});
```

That's it! You don't import anything in your app code at all.

<Callout type="info" title="Production builds are untouched">
  The plugin only runs during `vite dev`. `vite build` is untouched.
</Callout>
