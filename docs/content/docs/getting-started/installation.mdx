title: Installation
description: About 1 minute. Two steps, no changes to your app code.

## Requirements

- [Vite](https://vite.dev) 5 or later, on Node.js 18 or later.
- A React, Vue, Svelte, Solid or Astro app. See the [tested versions](/reference/framework-support#tested-versions).

## Installation

<Callout type="info" title="Let your agent do it">
  Add the [`spotnote-setup` skill](https://github.com/harukikuri/spotnote/tree/main/skills) to your coding agent, then ask it: `Set up Spotnote in this app.` It does both steps below, and can connect itself through [MCP](/guides/mcp).
</Callout>

<Steps>
<Step>

### Install the package

```bash tab="npm"
npm install -D spotnote
```

```bash tab="pnpm"
pnpm add -D spotnote
```

```bash tab="yarn"
yarn add -D spotnote
```

It's a dev dependency because it only runs in your dev server.

</Step>
<Step>

### Add the plugin

Add `spotnote()` to `plugins` in `vite.config.ts`. Anywhere in the array works.

```ts tab="React" title="vite.config.ts"
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [react(), spotnote()], // [!code highlight]
});
```

```ts tab="Solid" title="vite.config.ts"
import { defineConfig } from 'vite';
import solid from 'vite-plugin-solid';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [solid(), spotnote()], // [!code highlight]
});
```

```ts tab="Vue" title="vite.config.ts"
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [vue(), spotnote()], // [!code highlight]
});
```

```ts tab="Svelte" title="vite.config.ts"
import { defineConfig } from 'vite';
import { svelte } from '@sveltejs/vite-plugin-svelte';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  plugins: [svelte(), spotnote()], // [!code highlight]
});
```

```ts tab="Nuxt" title="nuxt.config.ts"
import spotnote from 'spotnote'; // [!code highlight]

export default defineNuxtConfig({
  vite: { plugins: [spotnote()] }, // [!code highlight]
});
```

```js tab="Astro" title="astro.config.mjs"
import { defineConfig } from 'astro/config';
import spotnote from 'spotnote'; // [!code highlight]

export default defineConfig({
  vite: { plugins: [spotnote()] }, // [!code highlight]
});
```

SvelteKit, React Router and SolidStart have a `vite.config` of their own: add it there, as above (SolidStart 1: under `vite.plugins` in `app.config.ts`). See [Meta-frameworks](/reference/framework-support#meta-frameworks).

</Step>
</Steps>

**Done.** You don't import anything in your app code.

<Callout type="info" title="Production builds and tests are untouched">
  The plugin only runs during `vite dev`. `vite build` doesn't include it (unless you turn on a [staging build](/guides/staging)), and neither do Vitest runs, so your tests' DOM and snapshots stay the same.
</Callout>
