## Install the package

Add Spotnote as a dev dependency — it only ever runs in the dev server.

```bash tab="npm"
npm install -D spotnote
```

```bash tab="pnpm"
pnpm add -D spotnote
```

```bash tab="yarn"
yarn add -D spotnote
```

## Requirements

- **Vite** 5.0 or later
