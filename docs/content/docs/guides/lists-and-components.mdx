## Repeated elements

Elements rendered in a loop (`items.map(...)`, `v-for`, `{#each}`) all come from one line of source, so they all carry the same stamp. Spotnote tells them apart by **position**: which match it is, counting in DOM order.

When you pick one, the prompt names it:

```markdown
- text: "all"
- instance: 1 of 4 rendered from this line (by DOM order) — target the one matching the text above
```

The agent edits the line, so a style change usually affects every instance. If you only want one to change, say so in your note (for example, "only the active chip").

You don't need a `key` or any extra attribute for this.

<Callout type="warn" title="Reordering moves the note">
  Because instances are counted by position, a note on the 2nd item stays on
  whatever is 2nd after the list is sorted, filtered or reloaded with
  different data.
</Callout>

## Component boundaries

A stamp records where an element is **written**, which is inside a component's own file. If you click a button that comes from your `Button` component, the location points into `Button.jsx`, not the page that uses it.

That's why the prompt also includes the **source path**: the components that own each element from the app root down to the one you clicked, for example `App > Products > ProductCard`. With it, the agent can decide whether to change `ProductCard` itself or how `Products` uses it.

The source path is built from the elements on the page, so a component appears in it once per stretch of its own elements. When one component's elements wrap another's (a `Link` that wraps markup written in `Home`), the path can show a name twice: `App > Home > Link > Home`.

## Elements without a stamp

Some elements have no source location of their own:

- markup rendered inside a dependency (a UI library's components),
- HTML injected as a string (`dangerouslySetInnerHTML`, `v-html`, `{@html}`),
- DOM built by third-party widgets (charts, maps, editors).

Clicking one selects the **nearest ancestor that has a stamp**, and the prompt adds a line saying the clicked element isn't in your source. The agent gets the closest place in your code to start from. See [Limitations](/troubleshooting#limitations) for the full list.
