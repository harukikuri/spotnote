The prompt is plain Markdown. Paste it into Claude Code, Cursor, Codex or any chat, on its own or with your own lines around it.

Tired of pasting? [Connect your agent](/guides/mcp) and it picks up notes on its own.

## Write better notes

1. **Say the outcome, not the location.** The prompt already has the location. "Make this pill-shaped" is enough.
2. **One change per note.** For a change across several elements, write a note on each and paste the prompts together.
3. **Say "all" when you mean all.** For repeated elements, the prompt points at one instance. Write "all the cards", not "this card".
4. **Say when only this usage should change.** If the element comes from a shared component and you don't want every usage to change, say so.

## After the edit

Vite's hot reload shows the change. If the edit moved the element's opening tag to another line, its pin disappears. That's expected: see [A pin disappeared after an edit](/faq#a-pin-disappeared-after-an-edit).
