## How it works

<Diagram name="mcp" width={974} height={152} alt="Your app sends your note to spotnote-mcp over HTTP; your agent gets it with watch_notes over MCP, and answers with resolve_note; the reply goes back to your app." />

Your agent starts spotnote-mcp, a small server on your machine. Your app sends it each note you write, and your agent, watching, gets it through the [MCP tools](#mcp-tools). The agent's answer goes back the same way, and shows on the note.

## Set up

<Steps>
<Step>

### Add the server to your agent (once)

Pick your agent:

```bash tab="Claude Code"
claude mcp add --scope user spotnote -- npx -y spotnote-mcp
```

```bash tab="Codex"
codex mcp add spotnote -- npx -y spotnote-mcp
```

```json tab="Cursor" title="~/.cursor/mcp.json"
{
  "mcpServers": {
    "spotnote": { "command": "npx", "args": ["-y", "spotnote-mcp"] }
  }
}
```

```json tab="Gemini CLI" title="~/.gemini/settings.json"
{
  "mcpServers": {
    "spotnote": { "command": "npx", "args": ["-y", "spotnote-mcp"] }
  }
}
```

Or let your agent add it: the [`spotnote-setup` skill](https://github.com/harukikuri/spotnote/tree/main/skills) does this step too.

There's nothing else to run. The agent starts the server, and the launcher in your app connects to it on its own.

**You should see** **Connected** under [Settings → MCP](/guides/settings#mcp) once your agent is running.

<Callout type="info" title="Port 4848 taken?">

Set the same free port in two places:

- **Your agent:** add `-e SPOTNOTE_PORT=4900` to the Claude Code command, or `"env": { "SPOTNOTE_PORT": "4900" }` next to `"args"` in a JSON config.
- **Your dev server:** `spotnote({ port: 4900 })` in your Vite config (see [`port`](/reference/plugin-api#port)), or `SPOTNOTE_PORT=4900 pnpm dev`.

</Callout>

## MCP Tools

| Tool | What it does |
| --- | --- |
| `watch_notes` | Waits up to 50 seconds for notes that need the agent (new notes and your replies), then returns them. The agent calls it in a loop. |
| `list_notes` | Returns every open note. |
| `reply_note` | Writes a message to you on a note, usually a question. |
| `dismiss_note` | Closes a note without making the change, with the reason. |
| `resolve_note` | Marks a note done, with a short summary of the change. |

Each note comes with its id, its page, the same prompt that copying gives you, and the conversation so far.

## Where notes live

spotnote-mcp keeps your notes in `~/.spotnote/`, so every browser shows the same ones. See [Storage](/reference/storage#with-spotnote-mcp).

It listens on `127.0.0.1` only, so other devices on your network can't reach it.
