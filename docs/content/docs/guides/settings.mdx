---
title: Settings
description: See whether your coding agent is connected, and change Spotnote's look and where files open.
---

Open the launcher and click the gear (the third button) to open **Settings**. Each row has a **?**: hover it for what the setting does. Changes apply right away and are saved in your browser, per app (see [Storage](/reference/storage)).

## Coding agent

The row shows whether your agent is connected through [spotnote-mcp](/guides/mcp), updated live. Click it for its page: what connecting gives you, and when it isn't connected, the two steps to connect Claude Code (the command to add it, then what to ask it), each with a copy button.

| Status | Meaning |
| --- | --- |
| Connected | Your agent picks up notes as you write them. |
| Connecting… | It just started; your notes are syncing. |
| Not connected | No agent is running spotnote-mcp. |

## Accent color

The color of the outline, the labels and the pins. Yellow is the default; switch to orange, pink, violet, blue or green when yellow blends into your app.

## Theme

The icon at the top right of Settings. Click it to cycle through the options. It sets the look of Spotnote's own panels (the launcher, note panel and lists), not your app's.

| Option | Effect |
| --- | --- |
| System | Follows your OS setting, and switches when it does. |
| Light | Light panels. |
| Dark | Dark panels. The default. |

## Open files in

Where a file opens when you click its name: in the note panel's header, or in the agent's messages (`router.jsx:28`).

| Option | Effect |
| --- | --- |
| Auto | The default. Opens the file in the editor that's running, found by the dev server. If that editor's command-line tool isn't installed (VS Code's `code`, for example), it opens through the editor's URL instead. |
| VS Code, Cursor, Windsurf, Zed | Always opens in that editor, through its URL (`vscode://file/…`). Works without the editor running or its command-line tool installed. The browser may ask you to allow it the first time. |

If Auto finds no editor, a warning icon appears next to the link; hover it for why, and pick yours here. Set `LAUNCH_EDITOR` when starting the dev server to name an editor Auto doesn't recognise.

## Footer

The bottom of Settings shows which Spotnote version you're running, with a link to its GitHub repository.
