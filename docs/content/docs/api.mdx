## `spotnote()`

The only export — a single, self-contained Vite plugin. Import it as the default and add it to your `plugins` array.

```ts
import spotnote from 'spotnote';

export default defineConfig({
  plugins: [react(), spotnote()],
});
```

It takes **no options**. One call does everything:

- stamps `data-spotnote="file:line:column"` on host elements, and
- auto-injects the picker client via `transformIndexHtml`.

## Plugin order

React and Vue run their compilers at normal enforce, so `spotnote()` (`enforce: "pre"`) always beats them — order is flexible. **Solid** (and other JSX compilers that also run at `enforce: "pre"`, like Qwik) run in the same phase, so list `spotnote()` **before** them or the JSX is compiled away before it can be stamped:

```ts
plugins: [spotnote(), solid()]  // Solid — spotnote() must come first
plugins: [react(), spotnote()]  // React — either order works
plugins: [vue(), spotnote()]    // Vue — either order works
```

If a pre-compiling framework plugin is listed ahead of `spotnote()`, it warns in the dev console so the misorder isn't silent.

## Framework support

| Framework | How the stamp is added |
| --- | --- |
| React (Vite) | Standalone Babel JSX pass |
| Solid / Preact / Qwik (Vite) | Same Babel JSX pass |
| Vue (Vite) | Your app's `vue/compiler-sfc`, template elements |
| Next.js | Not Vite — on the roadmap |
