## Creating a note

1. Enter inspect mode (**open the launcher** or **hold `Alt`**).
2. **Click** an element — a pin drops and the note panel opens.
3. Type an instruction and press `Enter` (or click **↵ Add & copy**).

The note is saved and its pin stays on the element. Adding a note copies the agent-ready prompt to your clipboard right away. Closing the panel before that (× or `Esc`) discards the draft. A click on the page while the panel is open never reaches your app: it switches to the element you clicked, or closes the panel on empty space — unless you have unsent text (a new note, or an edit you haven't saved), in which case the panel shakes and keeps it.

## Editing a note

Click an existing pin to reopen it. The panel shows a **copy** button (top-right) and your note text prefilled. Edits save when the panel closes; press `Enter` to save and copy in one step. The copy button turns into a check when the prompt is on your clipboard.

## Deleting a note

Open the note and click the **trash** button. This removes the pin and its note.

## Storage

Notes and pins are stored in your browser's `localStorage` for the dev session. They persist across reloads but are local to your browser — nothing syncs across devices or teammates, and there's no server.

## The copied prompt

Copying a note produces a framework-neutral, agent-ready markdown prompt:

````markdown
## Request
make the padding bigger

## Target
- file: components/ProductCard.jsx
- line: 12, column: 6
- element: <button class="chip">
- text: "Add to cart"
- instance: 2 of 6 rendered from this line (by DOM order) — target the one matching the text above

## Source path (outer → inner)
App > Products > ProductCard

## Current computed styles
  padding: 6px 12px
  font-size: 14px
  …
````

Paste it into Claude Code, Cursor, or Codex — it has the exact file/line, the element, and its computed styles, so the agent can make the edit without guessing.

A few sections are conditional:

- **`instance`** appears only when the element is one of several rendered from the same source line.
- **`## Source path`** is the component nesting from the clicked element up to the app root, read off its ancestors' stamps (each element records its owning component; deduped, outer → inner). It gives the agent the composition context — so it can decide whether to edit the element's own component or the usage site a level up.
- If you click an element that carries **no stamp** (e.g. rendered by a dependency or injected via `v-html` / `dangerouslySetInnerHTML`), the note resolves to the nearest stamped ancestor and adds a line flagging that the exact target isn't in your source.
