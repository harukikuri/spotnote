## The launcher doesn't appear

Try these in order:

1. **Use your dev server.** Spotnote runs only in `vite dev`, not in a build or `vite preview`.
2. **Check the browser console** for errors loading `virtual:spotnote-client`.
3. **Check your HTML goes through Vite.** The client is added through Vite's `transformIndexHtml` hook. HTML served some other way never loads it.

## Hovering highlights nothing

Try these in order:

1. **Turn on selection mode.** Open the launcher. It should be yellow <LauncherIcon state="open" />, not grey <LauncherIcon state="paused" /> (paused). Or hold `Alt` / `⌥ Option`.
2. **Look at the terminal for `[spotnote] skipped …`.** That file couldn't be parsed, so its elements aren't stamped. See [Warnings](/reference/plugin-api#warnings).
3. **Check the file type.** Only `.jsx`, `.tsx`, `.vue` and `.svelte` files are stamped. In dev tools, look for a `data-spotnote` attribute on the element.

## A pin disappeared after an edit

**Expected.** A note finds its element by the element's **source location** (file, line, column), plus its position for repeated elements.

| Your edit | The pin |
| --- | --- |
| Doesn't move the element's opening tag (classes, text, children) | Stays. |
| Moves the tag to another line or column (say, a new line above it) | Disappears. The note is marked **Not found** in the notes list. |

From the notes list, a **Not found** note can still be:

- **copied**: you get its last prompt, plus a line telling the agent the location may have moved;
- **deleted**: for example, once the agent has made the change.

It can't be opened. If the element comes back to the same location (say, you undo the edit), the note finds it again.

## My notes are gone

**Check the port.** Notes are saved per browser and per address. If Vite started on `5174` because `5173` was busy, your notes are still under `5173`. See [Storage](/reference/storage).

## The prompt points at the wrong file

**Tell the agent which usage you mean.** You likely clicked an element from a shared component, so the location is inside that component's file. The **source path** in the prompt shows where it's used.
