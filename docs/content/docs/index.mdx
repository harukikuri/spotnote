## Try it in 2 minutes

1. Install: `npm install -D spotnote`
2. Add `spotnote()` to `plugins` in `vite.config.ts`
3. Run your dev server, click the round `+` in the corner, then click any element

Full steps: [Installation](/getting-started/installation).

## What you get

- **The exact spot.** The prompt names the **file, line and column** where the element is written.
- **The right instance.** If the element is one of many (a card in a grid), the prompt says which one.
- **Fewer tokens.** Your agent doesn't search the codebase or guess which button you meant.

## Works with

- React, Solid, Vue and Svelte, on Vite 5 or later
- Any agent you can paste text into: Claude Code, Cursor, Codex, a chat window

Versions and caveats: [Framework support](/reference/framework-support).
