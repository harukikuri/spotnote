Spotnote is a **dev-only Vite plugin**. In your running app, click an element and write what should change. Spotnote copies a prompt for your coding agent that names the **file, line and column** where that element is written.

<SpotnoteFullDemo />

## Why

Describing UI to an agent in words loses information. "Make the button in the hero rounder" leaves the agent to search the codebase and guess which button you mean. Spotnote skips the guessing: the prompt says exactly where the element is defined, which instance you picked if it's one of many, and which components it sits inside. No searching also means fewer tokens spent.

## Works with

React, Solid, Vue and Svelte 5 on Vite. See [Framework support](/reference/framework-support) for versions and caveats.
