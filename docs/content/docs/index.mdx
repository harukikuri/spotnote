title: What is Spotnote?
description: Point at an element in your running app, and give your coding agent its exact source location.
---

Spotnote is a **dev-only Vite plugin**. In your running app, click an element and write what should change. Spotnote copies a prompt for your coding agent that names the **file, line and column** where that element is written.

<SpotnoteFullDemo />

## Why

Describing UI to an agent in words loses information. "Make the button in the hero rounder" leaves the agent to search the codebase and guess which button you mean. Spotnote skips the guessing: the prompt says exactly where the element is defined, which instance you picked if it's one of many, and which components it sits inside.

## What you paste

```markdown
## Request
Make the card titles larger

## Target
- file: pages/Home.jsx
- line: 36, column: 15
- element: <h3>
- text: "Click to source"
- instance: 1 of 6 rendered from this line (by DOM order) — target the one matching the text above

## Source path (outer → inner)
App > Home

## Current computed styles
  font-size: 16px
  font-weight: 700
  …
```

Every field is described in [Prompt format](/reference/prompt-format).

## Works with

React, Solid, Vue and Svelte 5 on Vite. See [Framework support](/reference/framework-support) for versions and caveats.
