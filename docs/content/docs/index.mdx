Spotnote is a Vite plugin that lets your teammate create feedback — with AI-ready code context.

<SpotnoteFullDemo />

## Features

- **Element selection** — click any element to pin a note to it
- **Code context** — each note includes source code information via a manifest
- **Cross-build survival** — notes persist across deploys via element fingerprinting
- **AI-ready** — copied notes include full code context that AI agents can act on
- **Framework support** — React, Vue, and Svelte
