## What you get

- **The exact spot.** The prompt names the **file, line and column** where the element is written.
- **Fewer tokens.** Your agent doesn't search the codebase or guess which button you meant.
- **Stay in the browser.** With MCP, your agent picks up your notes automatically.
- **Zero setup.** One line in `vite.config`, nothing to import in your app code.
- **Production stays clean.** Spotnote runs only in `vite dev`.
- **Everything is local.** No account, no cloud.

## Works with

React, Solid, Vue and Svelte, on Vite 5 or later. See [Framework support](/reference/framework-support).
